# 🧬 Molecular GPT — AI Molecular Intelligence Platform

Complete single-file frontend + FastAPI backend + PostgreSQL schema.

## Quick Start
- Open `frontend/index.html` directly in any browser — fully working!
- For backend: `cd backend && pip install -r requirements.txt && uvicorn main:app --reload`
- For database: `psql -f database/schema.sql`

## Pages Included
Login, Signup, Dashboard, Molecular Chat, Molecule Builder (interactive), 
3D Visualizer (Three.js), Experiments, Research Library, AI Lab, 
Saved Molecules, Profile, Settings

## Free APIs
- PubChem (no key), HuggingFace (free), Anthropic/OpenRouter (free tier)
